# 📰 Fake News Detection With Machine Learning

## 📖 Overview
This project tackles the modern challenge of digital misinformation by building a Natural Language Processing (NLP) model to identify fake news. The notebook walks through the complete text analytics pipeline—from importing and extensively cleaning text data to visualizing word frequencies with word clouds, and finally training a Recurrent Neural Network (RNN) to classify articles as real or fake.

## 🎯 Objective
The primary objective is to apply deep learning techniques to text classification. By implementing an RNN, the project aims to capture the sequential context of words within news articles, providing a highly accurate predictive model to distinguish between factual reporting and fabricated news.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Deep Learning Framework:** TensorFlow / Keras (RNN)
* **NLP Processing:** NLTK (Stopwords, Tokenization)
* **Data Manipulation & Visualization:** pandas, NumPy, Matplotlib, WordCloud

## 🧠 Key Learnings & Skills Demonstrated
* **Text Pre-processing:** Cleaning raw text data by removing null values, punctuation, and standard stopwords to reduce noise.
* **Tokenization & Sequencing:** Converting text into numerical tokens and sequences suitable for recurrent neural network input.
* **Exploratory Data Analysis (EDA):** Generating Word Clouds to visually contrast the most frequent terms used in true versus fake news datasets.
* **Deep Learning Architecture:** Building and training a Recurrent Neural Network (RNN) designed specifically to handle sequential text data.
* **Model Evaluation:** Assessing the RNN's performance using standard classification metrics like accuracy and interpreting the Confusion Matrix.

## 🚀 Getting Started

### 📋 Prerequisites
To run this project, you will need:
* Python 3.x
* Jupyter Notebook or JupyterLab

### ⚙️ Installation & Setup

1. Clone the repository to your local machine:
   git clone https://github.com/Raaaj2005/Fake-News-Detection-With-Machine-Learning.git

2. Navigate into the downloaded project folder:
   cd Fake-News-Detection-With-Machine-Learning

3. Install the required dependencies:
   pip install tensorflow pandas numpy nltk matplotlib wordcloud jupyter

4. Launch the Jupyter Notebook environment:
   jupyter notebook

5. Open the project's .ipynb file and execute the cells sequentially to process the text data and train the RNN model.
